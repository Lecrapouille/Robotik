# 📚 RobotIK documentation

If robotics is new to you, read [Robotics in ten minutes](concepts/01-robotics-in-ten-minutes.md) first. Then follow the [tutorials](tutorials/README.md) in order. After them, open the other pages when you need them. They are in five folders. Each folder holds one kind of page, so you know what a page gives you before you open it.

| Folder | A page… | Open it when |
|--------|---------|--------------|
| [Tutorials](tutorials/README.md) | teaches by doing, step by step | you start with RobotIK |
| [Guides](guides/README.md) | gives the steps of one task | you know what you want to do |
| [Concepts](concepts/README.md) | explains why RobotIK works this way | you want to understand a choice |
| [Reference](reference/README.md) | lists keys, classes and words | you need one fact |
| [Case studies](case-studies/README.md) | shows one demo plugin from end to end | you want a complete example |

- *"I just want to see something move."* → [Getting started](tutorials/01-getting-started.md)
- *"I want to change a test without compiling."* → [A cube in a box](tutorials/03-a-cube-in-a-box.md), then [the scenario file](reference/scenario-file.md)
- *"I want to write my own robot program."* → [Your first plugin](tutorials/04-your-first-plugin.md)
- *"Which method do I call?"* → [API reference](reference/api.md)
- *"I want to change RobotIK itself."* → [Architecture](concepts/06-architecture.md), and [AGENTS.md](../AGENTS.md) for the conventions
