# Tutorials

[⏫ Documentation](../README.md)

A tutorial teaches by doing. Follow the steps in order: each one gives a
result that you can see. You do not need any robotics background. If a word
is new, look in the [glossary](../reference/glossary.md).

1. [Getting started](01-getting-started.md): build RobotIK, watch a robot
   in the simulator, run the same scenario without a window, break a test
   on purpose, run an experiment. About 20 minutes, most of it compilation.
2. [Three programs, one per layer](02-three-programs.md): move a robot,
   run a skill, then reach a goal, each time in a few lines of C++.
3. [A cube in a box](03-a-cube-in-a-box.md): add objects to a world, write
   an assertion, and see what a seed changes. YAML only.
4. [Your first plugin](04-your-first-plugin.md): the HelloWorld plugin in
   four lessons (a mission, a joint, inverse kinematics, a skill and a
   behavior tree).
5. [Your own plugin](05-your-own-plugin.md): copy HelloWorld, rename it,
   build it and run it.
6. [A planned pick and place](06-a-planned-pick-and-place.md): give a goal
   instead of a behavior tree, and watch the planner plan again after a
   fault.

After the tutorials, the [guides](../guides/README.md) give the steps of one
task, and the [concepts](../concepts/README.md) explain why RobotIK works
the way it does.
