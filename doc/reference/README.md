# 📘 Reference

[⏫ Documentation](../README.md)

A reference page is a list of facts: keys, values, classes. Open it when you
need one fact; it does not explain the ideas (see the
[concepts](../concepts/README.md)).

Files:

- [The world file](world-file.md): entities, models, tools, several robots,
  sensors and actuators.
- [The scenario file](scenario-file.md): controller, perception, physics,
  the end of a run, assertions and conditions, trajectories, the same from
  C++.
- [The experiment file](experiment-file.md): cases, overrides, seeds.
- [Plugins](plugin.md): the plugin class, its lifecycle, `plugin.yaml`, where
  the hosts look for plugins, the rules of a good plugin.
- [The PDDL planner: reference](pddl-planner.md): the `controller.planner`
  keys, the planner metrics, the C++ calls, debugging.

Code and words:

- [API reference](api.md): the classes a plugin uses, grouped by task.
- [Glossary](glossary.md): the words of RobotIK, each one defined once.
